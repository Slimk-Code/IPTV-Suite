Changelog
All notable changes
v1.0.0 — IPTV Playlist Manager & Stream Player
2026-07-03
Added
  • Foundation for IPTV playlist management and stream playback.
  • Three import methods: M3U (URL or file), Xtream Codes API, Stalker Portal (MAC-based).
  • Home dashboard with recently watched and an all-playlists grid.
  • Favorites to pin and surface your go-to channels.
  • Playlist management: create, browse, open, delete, and more.
  • Channel browser with Live / VOD / Series segmentation, category groups, and pagination.
  • Native player with HLS / MPEG-TS playback, SRT/VTT subtitles, and URL copy/share.
Changed · Removed · Fixed
  • Initial release — no prior history.
